# Design system

Dark forest `#0B1011`, elevated green `#151D1B`, ivory `#F4F1E9`, muted text `#A7ADA7`, brass `#C5A46D`, sage `#83B5A3`. Light mode uses ivory `#F2F0E8`, deep green text and darker brass for readable contrast. Colors are CSS variables, not an inverted filter.

Instrument Serif brings editorial display character; Manrope handles readable interface text; monospace is reserved for clocks and chain identifiers. Fonts are bundled locally. A small number of border radii and consistent thin separators keep the club identity cohesive.

The hero is original CSS perspective geometry plus authored SVG chess pieces. No stock image, generated person, fake online count, fake transaction or invented ranked player appears. Lower sections use editorial headlines, asymmetric artwork and alternating compositions.

Responsive behavior reorganizes the board above supporting panels, collapses navigation and turns bot tiles into compact mobile rows. The game route prioritizes the board over decorative content. Reduced-motion locks the hero camera and disables transitions; critical interactions remain available through text controls. Focus indicators and a skip link are present. This is not a formal accessibility certification.
